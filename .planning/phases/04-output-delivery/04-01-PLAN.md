Add four new route handlers to the existing jobs router in api/jobs.py. IMPORTANT: declare the exact-match routes BEFORE parameterized routes to avoid FastAPI path ambiguity.

1. **Helper function `_get_completed_job_or_raise(job_id, current_user)`:**
   - Calls `job_manager.get_status(job_id)` — 404 if None
   - Checks `user_id` match — 403 if mismatch
   - Checks `status == "completed"` — 409 if not completed
   - Calls `job_manager.get_result(job_id)` — 404 if None
   - Returns `(job_state, result)` tuple

2. **`GET /{job_id}/files` → `get_job_files()`** (response_model=JobFilesResponse):
   - Uses `_get_completed_job_or_raise`
   - Reads emp_cod, vigencia from job_state (NOT from ProcessorResult — it lacks those fields)
   - Builds summary: total=len(result.relatorio), errors=count of rows where status column (index 4) != "OK", skipped=0 (no skip tracking in v1)
   - Builds files list: always include main txt entry + csv entry
   - If result.notas_vig_errada is truthy, add a txt_split entry for each key
   - URLs are relative: `/jobs/{job_id}/download/txt`, `/jobs/{job_id}/download/csv`, `/jobs/{job_id}/download/txt/{vig_key}`

3. **`GET /{job_id}/download/txt` → `download_txt()`:**
   - Uses `_get_completed_job_or_raise`
   - Returns `Response(content=result.conteudo_final.encode("utf-8"), media_type="text/plain; charset=utf-8", headers={"Content-Disposition": f'attachment; filename="{emp_cod}_{vigencia}.txt"'})`

4. **`GET /{job_id}/download/csv` → `download_csv()`:**
   - Uses `_get_completed_job_or_raise`
   - Import csv, io at top of file
   - Import _CABECALHO from services.report (this is safe — services/report.py only imports from config at module level, but _CABECALHO is a plain list constant; if the import triggers config.py loading, use a local copy of the header list instead)
   - Actually: to avoid importing services.report (which imports config.py and would fail the G-drive linter), define _CSV_CABECALHO as a module-level constant in api/jobs.py matching the exact same 10 columns
   - Build CSV: `buf = io.StringIO()`, `writer = csv.writer(buf, delimiter=";")`, writerow header, writerows relatorio
   - Encode: `buf.getvalue().encode("utf-8-sig")`
   - Return Response with media_type="text/csv; charset=utf-8", filename="relatorio_{emp_cod}_{vigencia}.csv"

5. **`GET /{job_id}/download/txt/{vigencia}` → `download_split_txt()`:**
   - MUST be declared AFTER the `/download/txt` route to avoid path collision
   - Uses `_get_completed_job_or_raise`
   - Checks `vigencia in (result.notas_vig_errada or {})` — 404 if not found
   - Builds header: `from core.txt_builder import montar_cabecalho` (this is safe — txt_builder has no config.py import)
   - `dt_iso = f"{vigencia[2:]}-{vigencia[:2]}-01T00:00:00"` where vigencia is MMYYYY
   - `cab = montar_cabecalho(result.im_tomador_cab, result.razao_tomador_cab, dt_iso)`
   - Content: `"\n".join(([cab] if cab else []) + linhas).encode("utf-8")`
   - Return Response with filename="{emp_cod}_{vigencia_key}.txt"

Add necessary imports at top: `import csv`, `import io`, `from fastapi import Response`, and add `JobFilesResponse, FileEntry, JobSummary` to the models import line.
